# ✈️ Travel — Ճամփորդական Հարթակ

**Travel**-ը վեբ հավելված է, որտեղ օգտատերերը կարող են դիտել ճամփորդական ուղղություններ, ինֆորմացիա ստանալ տարբեր երկրների մասին և կազմակերպել իրենց ճամփորդությունները։

🌐 **Կայք՝** [travel-weld-iota.vercel.app](https://travel-weld-iota.vercel.app)
📂 **Կոդ՝** [github.com/Narek-Momchyan/TRAVEL](https://github.com/Narek-Momchyan/TRAVEL)

---

## 💡 Ի՞նչ է անում հավելվածը

- 🔍 Ճամփորդական ուղղությունների դիտում և որոնում
- 🌍 Երկրների ու քաղաքների մասին մանրամասն ինֆորմացիա
- 🤖 **AI Chat** — ներկառուցված արհեստական բանականության հետ զրուցարան, որը կօգնի ճամփորդությունը պլանավորել
- 🔐 **Օգտատիրոջ գրանցում և մուտք** — անվտանգ authentication համակարգ
- ✉️ **2FA էլ. փոստով** — երկքայլ հաստատում՝ հաշիվը պաշտպանելու համար
- 📱 Ռեսպոնսիվ դիզայն — հարմար ինչպես desktop-ի, այնպես էլ բջջայինի վրա

---

## 🛠️ Օգտագործված տեխնոլոգիաներ

| | Տեխնոլոգիա | Պատճառ |
|---|---|---|
| **Frontend** | Next.js (React) | Արագ, SEO-friendly, server-side rendering |
| **Backend** | Django (Python) | Հուսալի REST API, ուժեղ admin panel |
| **Deployment** | Vercel | Ավտոմատ deploy, անվճար hosting |
| **DevOps** | Docker | Հեշտ գործարկում ցանկացած համակարգչի վրա |

---

## 👨‍💻 Ի՞նչ սովորեցի այս պրոյեկտից

- Fullstack հավելվածի ստեղծում՝ frontend-ի և backend-ի կապակցմամբ
- REST API-ի նախագծում Django-ով
- Next.js-ի server-side rendering հնարավորությունների կիրառում
- Docker-ի միջոցով ամբողջ պրոյեկտի containerization
- Vercel-ով production deployment
- AI API-ի ինտեգրում և chat interface-ի կառուցում
- Օգտատիրոջ authentication և session management
- Էլ. փոստով 2FA-ի իրականացում՝ անվտանգ մուտքի համար

## 🚀 Տեղական գործարկում

```bash
git clone https://github.com/Narek-Momchyan/TRAVEL.git
cd TRAVEL
docker-compose up --build
```

Հավելվածը կբացվի՝ [http://localhost:3000](http://localhost:3000)
